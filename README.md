# Practica Technische Natuurkunde

Deze repository bevat de bestanden en materialen voor de **practica van Technische Natuurkunde**.

De materialen zijn georganiseerd per leerjaar en vervolgens per practicum. Hier vind je onder andere Python-code, databestanden, afbeeldingen en andere bestanden die tijdens de practica worden gebruikt.

## Structuur

De repository is globaal als volgt opgebouwd:

```text
Practica/
│
├── Leerjaar 1/
│   ├── Practicum 1_1/
│   ├── Practicum 1_2/
│   └── ...
│
├── Leerjaar 2/
│   ├── Practicum 2_1/
│   ├── Practicum 2_2/
│   └── ...
│
└── README.md
```

Ieder practicum heeft een eigen map met de bestanden die voor dat practicum nodig zijn.

## Repository gebruiken

Je kunt de volledige repository downloaden via **Code → Download ZIP** of de repository clonen met Git:

```text
git clone <repository-url>
```

Na het downloaden kun je naar de map van het betreffende leerjaar en practicum navigeren.

## Python

Voor sommige practica wordt gebruikgemaakt van Python. Hiervoor werken we met een aparte conda environment. Welke packages nodig zijn, staat bij het betreffende practicum aangegeven.

Een nieuwe omgeving kun je bijvoorbeeld maken met:

```text
conda create -n practicum python -y
conda activate practicum
```

Installeer vervolgens de packages die voor het betreffende practicum nodig zijn.

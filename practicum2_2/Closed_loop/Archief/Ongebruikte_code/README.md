# Ongebruikte code

Gearchiveerd bij het opschonen van stap 4. Het actieve script.ipynb gebruikt deze bestanden niet.

- `closed_loop/figuren.py`: grafieken maken en exporteren.
- `closed_loop/tuning.py`: PID-metingen beoordelen, meetplannen en gain scheduling.
- `closed_loop/meting.py` en `__init__.py`: kopie van voor het verwijderen van de oude stap-4- en stap-5-aliassen.
- `tests/test_tuning.py`: tests voor de gearchiveerde afstelfuncties.
- `tests/test_pid.py`: kopie van de tests met de oude functienamen.
- `tests/test_firmware.cpp` en `tests/stubs/`: oude firmwaretest; verwijst naar een eerdere sketch en is geen actuele test.

Deze bestanden zijn naslag. Herstel bij hergebruik de benodigde imports en paden.
De actieve tests staan in `../../tests/`.
